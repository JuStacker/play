# 소녀전선2 가챠정보

출처: https://gf2.haoplay.com/game/probability.html

## 픽업 캐릭터 뽑기 (지정 발주)

### 확률(100% 기준)

- S(정예 인형) 확률: 0.6 (천장 포함 누적 1.89%)
- A(표준 인형 + 표준 무기) 확률: 6 (표준 인형 3 + 표준 무기 3)
- B(구형 무기) 확률: 나머지 (93.4)

#### 확률업 (픽업)

- S 등장 시: 50% 픽업 정예 인형 / 50% 비픽업 정예 인형
- A 등장 시: 25% 픽업 표준 인형 / 75% 비픽업

#### 픽뚫 보장

- 픽업이 아닌 S가 나오면(픽뚫), 다음 S는 100% 픽업 확정

#### 천장

- 10회: A 또는 S 확정 보장 (B 없음)
- 58회 연속 S 미획득 시 소프트 천장 시작, 회당 4.5%p 증가
- 80회: S 100% 확정 (하드 천장)

## 픽업 무기 뽑기 (군비 강화)

### 확률(100% 기준)

- S(정예 무기) 확률: 0.7 (천장 포함 누적 2.18%)
- A(표준 무기) 확률: 7
- B(구형 무기) 확률: 나머지 (92.3)

#### 확률업 (픽업)

- S 등장 시: 75% 픽업
- A 등장 시: 75% 픽업

#### 픽뚫 보장

- 픽업이 아닌 S가 나오면(픽뚫), 다음 S는 100% 픽업 확정

#### 천장

- 10회: A 또는 S 확정 보장 (B 없음)
- 50회 연속 S 미획득 시 소프트 천장 시작, 회당 5%p 증가
- 70회: S 100% 확정 (하드 천장)

## 참고: 그 외 가챠 (시뮬레이션 대상 아님)

### 일반 발주 (상시 가챠)

- S(정예, 인형+무기): 0.3 + 0.3 = 0.6
- A(표준, 인형+무기): 3 + 3 = 6
- B(구형 무기): 나머지 (93.4)
- 픽업: "선택 확률 UP" — 선택 대상 50% 확률로 등장, 픽뚫 시 다음은 100% 확정
- 천장: 지정 발주와 동일 (10회 보장 / 58회부터 4.5%p 증가 / 80회 확정)

### 새단장 발주 (코스튬 가챠)

- 한정 보상: 0.02% (누적 1.1776%)
- 희귀 보상: 4.78% (누적 16.0255%)
- 일반 보상: 95.2% (누적 82.8%)
- 천장(한정 보상 확률 증가): 26~49회 회당 +0.01%p → 50~69회 회당 +0.02%p → 70~79회 회당 +0.15%p → 80~100회 회당 +0.5%p, 100회 확정
- 10회마다 희귀 이상 확정, 30회마다 금색 볼 확정
- 중복 시 토큰 전환: 한정 코스튬 1400개, 희귀 코스튬 260개, 한정 파츠 160개, 희귀 파츠 135개

## 시뮬레이션 설계 메모

- 캐릭터/무기 카운터는 가챠 타입별로 독립적이며 이월됨 (ZZZ와 동일 구조)
- ZZZ 시뮬레이터(`GachaTableGenerlator`) 대비 차이점:
  - 소프트 천장 증가폭이 등급 A는 없고 S만 적용 (ZZZ는 A 등급도 소프트 천장 있음 — 확인 필요)
  - 10회 단위 "A 또는 S 확정" 보장이 추가로 있음 (ZZZ에는 없는 규칙)
  - S 등급 픽업 확률이 50%(캐릭터) / 75%(무기)로 이미 명시돼 있어 ZZZ의 `winRate`(0.5 / 0.75)와 동일한 값
